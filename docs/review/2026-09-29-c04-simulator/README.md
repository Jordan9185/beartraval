## 發現的環境問題

- 本機 `supabase start` 只掛載啟動當下 Edge Function 引用到的 `ai/` 檔案；之後新增的 `ai/shared/tasks.ts` 未掛載，所有 AI 入口啟動失敗（`Module not found`）。重啟本機 Supabase 可恢復。雲端 `functions deploy` 會打包引用檔案（`ask-trip` 自 9/24 即跨目錄引用並已部署），此問題只影響本機；C07 部署後仍應實測每個入口。
