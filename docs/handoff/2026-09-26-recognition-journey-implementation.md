## 已開發並部署

- 收藏詳情與清單以「排進旅程」作為主動作。選日期後，已定位收藏可看到順路估算；只有韓文店名與地址線索時，也可先建立待定位 Stop，顯示「路線未估算」。收藏保留在列表，顯示第幾天，可直接打開該日。旅程、今天和司機卡沿用同一筆地址與來源。
- 收藏清單先載入收藏，再讀取行程日期；日期暫時無法讀取時，收藏與地址仍會顯示，不會因排程狀態查詢失敗變成空列表。
- `20260926000029_schedule_saved.sql` 已部署雲端。`schedule_saved` 檢查 Owner／Editor、同趟旅程、當天版本、重送及重複排程；只新增單一 Stop，不整日替換，也不更動既有 Fixed Stop。待定位 Stop 後續確認座標會同步收藏；移除 Stop 會解除排程關聯。
- 商品詳情的有來源店家候選可按「安排購買」選日期。店名、韓文地址與來源保存在商品上，並建立待定位 Purchase Stop；購物清單、旅程和今天都顯示選中的店家。畫面一律顯示「可詢問、販售與庫存未知」，沒有座標就不計路線。
- `20260926000030_schedule_shopping_store.sql` 已部署雲端。`schedule_shopping_store` 只接受該商品已儲存且來源吻合的候選；檢查權限、當天版本與重複排程。刪除購買站會清除選店資料，原始候選仍保留供重選。
- `20260926000031_verify_shopping_store_choice.sql` 已部署雲端。新版安排購買會再核對所選店名和地址，避免同一來源頁的分店候選重排後排錯店；六參數舊操作保留給已安裝版本。
- 「東京五天」及有指定想去點的行程樣板沿用現有 `parse-import`：使用者指定點與日期保留，沒指定日期才建議安排；套用正式旅程前仍需確認。本次未更動 AI 解析模型或 Edge Function。

## 真機驗收清單

1. 無垢屋人參雞或「무구옥」截圖：辨識後看韓文店名、地址與來源；加入收藏後，清單／詳情／司機卡資訊一致。排到指定日期，旅程與今天可看到地址；未確認地圖位置時沒有假圖釘或增加分鐘數。
2. 使用餅乾巢狀截圖和 LOE／Aesop 商品截圖：商品與店家分開；選一間有來源候選店安排購買。購物清單重開仍看得到所選店名和地址；今天可找到該購買站，並標示庫存未知。
3. 同一收藏或商品連點兩次、兩支手機同時改同一天：不產生重複站；版本過期會重新載入，需再確認。移除一站後可重新安排，原 Fixed Stop 不變。
4. 「東京五天」與明列想去點：草稿天數正確、指定點與日期不遺失；只有按「確認套用」才改正式旅程。
5. 分享 Threads／相簿圖片到 App：來源能回查；網頁來源按鈕不會混成店家選項。影片連結只有不可讀內容時保留來源並說明資訊不足。
