# AI 主線第一批實作交接

日期：2026-09-27。起始版本 `df20f4b`；範圍為 AJ-0 的可信度防護與 AJ-1 的收件入口／來源保存，不代表 AJ-0～AJ-4 全部完成。

## 已開發

- L03：最佳日只比較有估值的結果，選店不再用 `nil → 0`；未知日仍保留人工安排入口，顯示「路程無法估算」。
- L04：`DayPlan.from` 排除未定位座標時另保留固定事項名稱、時間、停留與排序。存在未定位 Fixed 時保守回報可行性未知；已定位 Fixed 缺時間也不能視為不存在。此版沒有精算未定位事項前後的餘裕。
- App 內新增「交給 AI 整理」：旅程頁（含空旅程狀態）、收件匣及未登入頁可貼文字／連結、選最多 10 張圖片。先寫 App Group，再由既有同步與 AI 流程整理；不需先選分類或 Trip。
- 保存成功與 AI 完成分開回報；未登入資料需登入後認領。保存中避免重複送出／關閉，失敗保留輸入，附件缺漏有明示。收件匣在整理或上傳中刷新狀態；純圖片且無標題的收件也有可辨識的列標題。
- 同網址不同文字／圖片不再於本機誤合併。migration 33 將後端去重改為內容指紋／client ID，保留原始列及 RPC 簽名；同 client ID 不同內容回 `CAPTURE_CONTENT_MISMATCH`。
- 同步時再核對伺服器內容指紋；舊後端若回傳同網址的另一份內容，新內容仍留在裝置，不會被當成功刪掉。
