# 外開地圖地址與收藏卡片點擊修正

## 問題與修正

- 已查到店名和當地地址時，部分外開地圖入口只傳店名。共用搜尋按鈕現在優先使用去除前後空白的當地地址，缺少地址才退回店名；Naver、Kakao、Google 的 App／網頁入口一致。收件、收藏、分享、行程匯入、待定位 Stop 及商品店家候選均接上現有地址欄位。
- 已確認座標的導航保留原行為。搜尋地址仍是線索，不會因此寫成已確認 Place 或參與路線估算，也不會新增 AI 呼叫。
- 個人收藏列的多個按鈕原本沿用 List 的 automatic 點擊行為，可能把整列變成按鈕。現在統一使用獨立按鈕樣式，地圖、確認、更正等各自命中。
- 共同收藏列原本在外層整張卡掛詳情點擊手勢。現在標題／地址／狀態區使用明確的詳情按鈕，底下「想去」「排進旅程」維持獨立動作。

## 驗證

- Swift 套件摘要：180 項測試、47 suites 通過（保留既有需整合環境而略過的測試）。新增地址優先、空白地址退回店名、多語地址在各地圖 App／網頁 URL 中保留的測試。
- 模擬器兩項 UI 回歸通過，使用正式的 SavedRow、PersonalInboxRow 與地圖元件，確認想去／排程不開詳情，點標題才開詳情；Naver／Kakao 只開對應網址且查詢內容為地址，更正按鈕只開更正頁。結果：`build/qa/map-address-buttons.xcresult`。
- Release 真機編譯成功，已安裝並啟動 Jordan 的 iPhone 15 Pro。地圖 UI 測試攔截外開網址，因此證明傳出地址正確，不代表地圖供應商的搜尋結果已人工核對。

## 交付邊界

- Jordan 手機實際收藏操作及地圖搜尋結果待使用者驗收。
