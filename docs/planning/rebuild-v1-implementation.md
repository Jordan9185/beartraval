## 工程決策與限制

- 本機 GPT 為預設。Claude 明確啟用後只影響新工作，不自動 fallback；既有帳號白名單繼續有效，未列入的新旅伴不能使用 AI，不能宣稱邀請後已自動取得額度。
- API key 僅在後端 `ANTHROPIC_API_KEY`，模型必須設定 `CLAUDE_AI_MODEL`；未設定明確失敗，不猜模型、不在文件或 App 保存 key。
- 每人每日 20／全體每日 100 工作是暫行工程防護，並非使用者決定的金額預算；搜尋與多輪請求仍可能各自有費用。
- SDK JSON 用量與解析串流最終回報可保存；未回報時保留未知。中斷工作不自動重跑。
- 地址、來源與座標分開保存。AI 建議沒有座標不能被視為不可安排；沒有證據也不能假稱找到地址、評分、路程或庫存。
- 地區匹配已核對既有站點 ID、候選來源及兩端相同具體區域文字，並排除僅有城市／國家名稱；聖水／弘大反例已通過本機測試。仍未證明實際交通距離與固定時段可行性，交付前必須真測。
- 使用 Claude 官方 [Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool) 的具引用搜尋接頭。搜尋可呼叫不等於真實資料品質已驗收。
